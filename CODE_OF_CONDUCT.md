# Code of conduct

Valet follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep criticism about the work. Harassment isn't welcome here, in any form.

To report a problem privately, use [GitHub's reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
or contact the maintainer through their GitHub profile. Reports are handled in confidence.
