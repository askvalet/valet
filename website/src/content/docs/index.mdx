## What it is

Valet is one Node process that talks to your services and draws them as live cards: what's playing, what's downloading, what's down, which lights are on. You describe the page in `config.yaml`. Secrets stay in your environment, and the browser never sees them. It uses about 65 MB of RAM and has no database.

It works with [185 integrations](/integrations/). If yours isn't one of them, [`api`](/integrations/api/) turns any JSON API into a card from YAML, with no code.

## The assistant is optional

Leave out the `assistant:` block and the page loses nothing. [Running with no AI](/assistant/no-ai/) is a supported way to use Valet, not a reduced one.

If you add a model, local or hosted, it answers with the same cards the page uses.

The security story is the valet key: the key that drives the car but can't open the boot. The assistant reads freely and changes nothing without your approval. Each tool is `read`, `write` or `control`, you set the [access level](/assistant/access/) per integration, and every `write` or `control` call stops and waits for you.

## Cards fit the space they get

Every widget is one card, and every card works at five sizes. Small and wide show its headline. Medium, tall and large show the card. You pick the size in YAML. In chat the same card comes out denser. See [sizes](/concepts/sizes/) and the [card gallery](/cards/).

## Your house, in three dimensions

With [Home Assistant](/integrations/homeassistant/) and a robot vacuum's map, Valet draws a floor plan with each room's lights. The same stage draws your PC from [`rgb-control`](/integrations/rgb-control/). These load only on pages that use them.
